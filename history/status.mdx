## What to do next

**Run the loop on CFFD API.** Every other repo on the list is a Boost33 product. CFFD is the only API among them, and an API is the best AFK candidate there is: one seam, deterministic assertions, no visual judgement anywhere in the loop.

Its `docs/build-order.md` holds nine vertical slices ready to become tickets, and slice 1 has no blockers.

## Then retire the second copies

**Two runners exist.** `afk-runner/afk.mjs` on the host, and `toolkit/sandcastle/main.mts` in a container. The second supersedes the first.

**The vault still holds** a portfolio dashboard, a decision record and a message bus that Linear and Nostos already provide.

Both are the same failure this whole system exists to prevent: one fact, two homes, and within a week one of them is lying.
